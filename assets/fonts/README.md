# Bundled fonts

The renderer examples bundle two regular-weight fonts under the SIL Open Font License 1.1:

- `jetbrains-mono/JetBrainsMonoNL-Regular.ttf`: JetBrains Mono NL 2.304, downloaded from
  <https://github.com/JetBrains/JetBrainsMono/tree/v2.304>. This no-ligature variant is used for
  the monospaced code rendering.
- `liberation-serif/LiberationSerif-Regular.ttf`: Liberation Serif 2.1.5, downloaded from
  <https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5>. Liberation Serif is
  an open font designed for metric compatibility with Times New Roman.

Each font directory contains its own `OFL.txt` license file.
